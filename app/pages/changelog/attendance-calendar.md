# PETER v0.9.6 — Attendance Calendar

**Beta Release** · Internal

## Overview

`v0.9.6` introduces a new calendar-based filtering system for attendance records.

This release makes it easier to navigate and review attendance history by selecting dates directly from a calendar interface.

Instead of relying on manual date selection alone, administrators can now use the calendar to quickly move between dates and view the corresponding attendance records.

## 📅 Attendance Calendar

The primary feature of this release is the new attendance calendar.

With the calendar filter:

* Attendance records can be filtered by a specific date.
* Users can easily navigate between different dates.
* Selecting a date updates the displayed attendance records.
* The calendar provides a more intuitive way to explore attendance history.
* Date selection is integrated directly into the attendance management interface.

The calendar is designed to make reviewing historical attendance data faster and more convenient.

## 🔎 Attendance Filtering

The new calendar system improves the overall attendance filtering experience.

Users can now:

* Select a specific date to view attendance records.
* Navigate through previous and upcoming dates.
* Quickly switch between dates without leaving the attendance interface.
* Use the calendar as the primary way to explore attendance history.

This provides a more natural workflow for reviewing attendance records across different days.

## 📌 What This Release Means

`v0.9.6` is a focused feature release centered around improving attendance management.

The introduction of the attendance calendar provides a simpler and more intuitive way to explore attendance history while laying the groundwork for more advanced attendance filtering and reporting features in future releases.
